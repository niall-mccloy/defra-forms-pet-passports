# Order pet passports

## Purpose

Allow Vets to order pet passports

---

## Page 1 : Start Page

### Heading

Order pet passports for a veterinary practice

### Content

Link text: Official Veterinarians (OVs)
URL: https://www.gov.uk/government/collections/official-veterinarians-ovs-and-ov-practices-forms-and-guidance

"EU pet passports can be ordered by veterinary practices in England, Scotland and Wales in multiples of 20. Only Official Veterinarians (OVs) can issue pet passports to pet owners."

### Inset text

"Each passport will have a unique ID number. It's important to record these in case you need to report a problem, for example a lost or damaged passport."

### Sub heading H2

Who can order pet passports

### Content

Pet passports can be ordered by the following if they work at a registered veterinary pet practice:

- administrative staff
- Official Vets (OVs)

### Sub heading h2

Cost

### Content

Each box of 20 passports costs £56.

### Button

Start now

### Sub heading h2

Before you start

### Content

You will need the following information

- veterinary practice details
- quantity (boxes of 20)
- contact name, telephone number and email address
